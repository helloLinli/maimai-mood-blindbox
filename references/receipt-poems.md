# 小票诗与祝福语手册

> 本文件由 `node engine/cli.js export-refs` 从 `engine/content.js` 与 `engine/blindbox.js` 生成，**请勿手改**。
> 要改情绪档案、权重或诗词，请改源码后重新生成，这样文档与代码不会走偏。


## 取用方式

- 每首诗的编号形如 `EO-01-3`；同一情绪按种子轮换，**避免连续两次给出同一首**。
- 一首 **3-5 行**，每行 **不超过 16 个汉字**（要适合 80mm 热敏纸的一行宽度）。
- 语音祝福以固定前缀开头：`叮——你的麦麦心情盲盒已出票。`

## EO-00 说不清 · 交给我决定

**推荐理由（3 选 1，印在小票「为什么是这一盒」）**

1. 说不清就可以不选。这一盒替你把决定做完，你只负责吃。
2. 经典款是最不容易出错的答案，今天先要一个不出错的下午。
3. 搭配里留了一点甜的，因为完全没惊喜的一餐也不好吃。

```text
是自己走过来的。
```
### EO-00-2

```text

```
### EO-00-3

```text

你只需要张开手。
```
### EO-00-5

```text

在你手上。
```
### EO-00-6

```text

```

**收尾语**：不用什么都想清楚，先吃饱。

## 写一首新的小票诗

**句式**：先给一个**具体的生活细节**（屏幕、纸袋、油印、薯条、热饮、窗、键盘声、版本号、门缝的光），再给一个**轻的转折或允许**。不要押韵强行，不要抒情排比。

**禁用词**：必须、应该、加油、别难过、想开点、一切都会好、你值得拥有。（这类句子是空话，读起来像广告。）

**检查**：读一遍，如果这句话放到一张真实的小票背面会显得做作，就重写。

**示例（新写）**

EO-01 加班：

```text
打印机还在响，
你数着还剩几页。
先吃一口，
页码不会跑。
```

EO-07 赶时间：

```text
红灯还有 42 秒，
刚好够咬一口。
今天你没迟到，
也没饿着。
```
