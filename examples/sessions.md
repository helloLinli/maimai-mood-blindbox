## 关于「换一盒」

上面每一次都给 3 个盲盒，只是默认揭晓其中 1 个。想看另外两盒：

```bash
node engine/cli.js box --mood overtime --budget 60 --avoid beef --date 2026-10-11T21:04:00
```

或者用 `--box 0|1|2` 指定要出哪一盒的小票，例如 `--box 2` 拿反套路款。
